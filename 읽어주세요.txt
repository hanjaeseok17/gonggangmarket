공강마켓 — 대학 캠퍼스 기반 중고거래 앱
=======================================

파일 두 개 모두 인터넷 연결 없이 더블클릭하면 브라우저에서 바로 열립니다.
외부 파일이나 서버가 필요 없는 단일 HTML 파일입니다.


1) 공강마켓_앱_프로토타입.html
   실제로 눌러볼 수 있는 모바일 앱 시제품입니다.
   매물 둘러보기, 채팅, 가격 제안, 안전결제, 문고리 거래까지
   화면 안에서 직접 조작할 수 있습니다.
   매물과 판매자, 대화는 모두 가상 데이터입니다.

   먼저 해볼 것
   - 하단 탭으로 화면 이동
   - 매물 선택 -> 채팅하기 -> 거래하기 -> 안전결제
   - 내 정보 -> 학교 인증 -> 학생증 보내기 (3초 뒤 승인)
   - 인증 후 등록 탭에서 물건 올리기


2) 공강마켓_PRD_SRS_v1.4.html
   기획 문서입니다. 제품 요구사항(PRD)과 시스템 요구사항(SRS)을
   한 문서에 담았습니다. 18개 장, 기능 요구사항 91건,
   화면 명세 18개, 인수 조건 25건.

   왼쪽 목차를 눌러 각 장으로 이동할 수 있습니다.


권장 브라우저: 크롬, 엣지, 사파리 (최신 버전)
